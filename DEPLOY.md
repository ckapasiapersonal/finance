## 🚀 Step-by-Step Deployment (100% FREE)

### Step 1: Deploy Backend to Render (₹0)

1. **Go to**: https://dashboard.render.com/register
2. **Sign up** with GitHub
3. **Click "New +"** → **"Web Service"**
4. **Connect GitHub**: Select `ckapasiapersonal/finance`
5. **Configure**:
   - **Name**: `finance-api` (or your choice)
   - **Region**: Singapore (closest to India)
   - **Branch**: `master`
   - **Root Directory**: Leave blank
   - **Runtime**: Python 3
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn server:app --host 0.0.0.0 --port $PORT`
6. **Environment Variables** (click "Add Environment Variable"):
   - Key: `PORT`, Value: `8001`
7. **Plan**: Select **"Free"** (₹0/month)
8. **Click "Create Web Service"**

**Wait 5-10 minutes** for deployment. You'll get a URL like:
```
https://finance-api.onrender.com
```

**Test it**: Visit `https://finance-api.onrender.com/` - should show:
```json
{"status":"ok","message":"Swing Bot Analyzer Running"}
```

---

### Step 2: Deploy Frontend to Vercel (₹0)

1. **Go to**: https://vercel.com/signup
2. **Sign up** with GitHub
3. **Click "Add New..."** → **"Project"**
4. **Import Git Repository**: Search for `finance`
5. **Select**: `ckapasiapersonal/finance`
6. **Configure**:
   - **Framework Preset**: Vite
   - **Root Directory**: `web-dashboard`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
7. **Environment Variables**: None needed for now
8. **Click "Deploy"**

**Wait 2-3 minutes**. You'll get a URL like:
```
https://finance-ckapasiapersonal.vercel.app
```

---

### Step 3: Connect Frontend to Backend

After both are deployed, you need to update the API URL:

1. **In your local project**, open: `web-dashboard/src/App.tsx`

2. **Find all instances** of `http://localhost:8001` (there are ~5-6)

3. **Replace with your Render URL**:
```typescript
// OLD:
fetch('http://localhost:8001/analyze/${symbol}')

// NEW:
fetch('https://finance-api.onrender.com/analyze/${symbol}')
```

4. **Save and commit**:
```bash
cd "d:\antigravity\RANDOM TASK\STOCK\SWING BOT 2.0"
git add web-dashboard/src/App.tsx
git commit -m "Update API URL to Render backend"
git push
```

5. **Vercel auto-redeploys** in 1-2 minutes

## 🚨 If Deployment Fails

**Render (Backend)**:
- Check logs for missing dependencies
- Verify `requirements.txt` has all packages
- Ensure `Procfile` exists with: `web: uvicorn server:app --host 0.0.0.0 --port $PORT`

**Vercel (Frontend)**:
- Ensure `vercel.json` exists
- Check build logs for npm errors
- Root directory must be `web-dashboard`
